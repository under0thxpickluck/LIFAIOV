## 固定UIコンポーネント

### ラックレール（`.rail`）— ヘッダ・固定
- 左: ブランドロゴ `LIFAI` + ドット点滅アニメ + `AI MUSIC NETWORK`
- 右: セクション名（`#rSec`）/ チャンネル番号（`#rCh`）/ ON AIR バッジ

- ← → ボタン（`#prev` / `#next`）
- 進行バー（`#tfill` / `#thead`）
- スライド番号（`#tcur` / `#ttot`）

### キーヒント（`.khint`）— 右上固定
- `← → / SPACE` 表示

### キーボード操作
| キー | 動作 |
|---|---|
| `→` `↓` `Space` | 次のスライドへ |
| `←` `↑` | 前のスライドへ |
| `Home` | 最初のスライド |
| `End` | 最後のスライド |

- 50px以上のスワイプで前後移動

## スペクトラム（`.spectrum`）JS仕様

- `data-bars="N"` で棒数を指定
- `data-live="1"` でアニメーション有効
- 中央が高い分布 + ランダムゆらぎ
- `@keyframes vu { from{scaleY(.35)} to{scaleY(1)} }` を動的注入
- `prefers-reduced-motion` 時はアニメなし
